## Running PlasMerge

```
python src/plasmerge.py \
       -s <sample name> \
       -a <gzipped GFA file> \
       -p <plasmid scores TSV file> \
       -b <plasmid bins TSV file> \
       -r <plasmid bin source> \
       -d <directory where Gurobi sol file is written> \
       -f <path to output TSV file> \
       -g <GC intervals file; optional> \
       -t <threshold; optional, default=0.05> \
       -o <plasmid score offset; optional, default=0.5>
```

Rough parameters description:
- `sample name`: string (example: `SAMN32247522`)
- `gzipped GFA file`: gzipped assembly graph in GFA format (example: `test/gfas/SAMN32247522.gfa.gz`)
- `plasmid scores TSV file`: file recording for each contig its plasmid score (between 0 and 1)  
  - Format: `<contig ID><TAB><plasmid score>`
  - Example: `test/scores/SAMN32247522.scores.tsv`
- `plasmid bins TSV file`: file recording the initial plasmid bins
  - Format: `<plasmid id><TAB><comma separated list of contigs in format contig:muliplicity><TAB><copy_number>
    where `copy_number` is optional and if absent the copy number of a plasmid bin is the minimum of the read depth
    of its contigs read in the GFA file.  
  - Example: `test/pls_bins/SAMN32247522.gp.tsv`, `test/pls_bins/SAMN32247522.pbf.tsv`
- `plasmid bin source`: string (in experiments: `gt` for ground truth, `gp` for gplas2, `mob` for MOB-recon, `pbf` for PlasBin-flow)
- `GC intervals file`: path to file describing the GC content ratio intervals  
  - Format: one floating number per line, increasing from `0` to `1`
  - Default: `0, 0.4,  0.45, 0.5, 0.55, 0.6, 1`
  - Example: `test/gc_intervals.txt`
- `threshold`: **Question** what is this parameter?
- `plasmid score offset`: float in [0,1]: used in the objective function to offset the plasmid score of each contig.

## Implementation notes

I (CC) modified a lot the initial code:
- `src/PBF_utils.py`: functions taken from the PlasBin-flow code;
- `src/gfa_fasta_utils.py`: functions to manipulate GFA and FASTA files;
- `src/convert_utils.py`: functions to convert the raw output of various tools (`gplas2, MOB-recon, PlasBin-flow`) in the plasmid bins format described above;
- `src/io_utils.py`: classes used to define the iput to PlasMerge; this was extensively rewritten;
- `src/merging.py`: main file (used to be `post_processing.py`) for merging bins for a sample, augmented by a main function to run it on all the samples in `test`; logging is to be done (ugly `print` for now);
- `src/plasmerge.py`: main PlasMerge script.

## Experiments

I (CC) ran the merging function of `src/merging.py` on 5 *E. coli* samples and on the ground ruth plasmid bins and the plasmid bins created by `gplas2, MOB-recon, PlasBin-flow` (script `test.sh`).

The data are organizd as follows:
- `test/gfas`: gzipped GFA files for the 5 samples;
- `test/scores`: plasmid scores fo the 5 samples obtained with `mlplasmid`;
- `test/ground_truth`: ground truth plasmid bins;
- `test/[mob,gplas,pbf]`: raw output of `MOB-recon, gplas2, PlasBin-flow` for the 5 samples;
- `test/pls_bins/`: reformatted plasmid bins (obtained by running `python src/convert_utils.py`);
- `test/gc_intervals.txt`: GC intervals (default values);
- `test/results`: results of PlasMerge on the five samples
  - `model`: `.sol` files created by PlasMerge
  - `[gt,mob,gp,pbf`]: merged bins TSV files for each tool and the ground truth bins (`gt`)
